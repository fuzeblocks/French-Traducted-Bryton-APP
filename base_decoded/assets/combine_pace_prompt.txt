        ## 最終輸出格式限制（嚴格執行）

        你必須將【執行階段 2】產出的 main_target 與 auxiliary_fields_black 內嵌放入【執行階段 1】產出的 coach_report 內部。

                請特別注意：移入時，必須完整保留且絕對不可覆蓋或刪除 coach_report 內原本已存在的任何其他欄位。

                預期的 JSON 結構範例如下（請以此巢狀結構為準）：

                {
                  "coach_report": {
                    "原本已存在的其他欄位1": "...",
                    "原本已存在的其他欄位2": "...",
                    "main_target": { /* 填入執行階段 2 的內容 */ },
                    "auxiliary_fields_black": { /* 填入執行階段 2 的內容 */ }
                  }
                }


        請保持專業、精確、去冗言的語氣，最終「僅」輸出一個純 JSON 字串，不可更動 key 的位置與名稱，且絕對不要夾帶任何 JSON 以外的 Markdown 說明、前言或後記。
